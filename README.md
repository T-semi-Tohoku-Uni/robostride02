## 📂 Git管理・除外ポリシー (`.gitignore`)

当プロジェクトは、STM32CubeMXで生成したコードをベースに、**CMake + VS Code** 環境で開発を行うための設定ファイル管理ルールを適用しています。
ローカル環境への依存を無くし、クリーンなリポジトリを保つため、以下のファイル群はGitの管理から除外しています。

### 1. STM32CubeMX & 各種IDE
* **除外対象**: `.mxproject`、`*.ioc.bak`、MDK-ARM (Keil) や STM32CubeIDE 固有のプロジェクトファイル（`.settings/`、`.project` など）
* **理由**: 開発環境をVS Code + CMakeに統一しているため、他のIDE用ファイルやCubeMXのバックアップファイルは共有しません。ピン割り当てやクロック設定などのハードウェア構成の「正」として、`.ioc` ファイル本体のみをバージョン管理しています。

### 2. ビルド成果物 & CMake 中間ファイル
* **除外対象**: `build/`、`Debug/` などの出力ディレクトリ、コンパイル済みバイナリ (`*.elf`, `*.hex`, `*.o` など)、および CMakeの中間生成ファイル (`CMakeCache.txt`, `CMakeFiles/`)
* **理由**: ビルド成果物はソースコードからいつでも再生成可能であるため除外します。また、誤ってインソースビルド（ルートディレクトリでの `cmake` 実行）をしてしまった場合でも、生成された中間ファイルによってGit履歴が汚れないようフェイルセーフとして除外指定しています。
* **注記**: `compile_commands.json` は絶対パスを含みローカル環境に依存するため、ルートに配置した場合でも管理対象外としています。

### 3. VS Code 設定
* **管理（共有）対象**: `.vscode/` 以下の `settings.json`、`tasks.json`、`launch.json`、`extensions.json`
* **除外対象**: `c_cpp_properties.json` およびユーザー個人のローカルワークスペース設定
* **理由**: 本プロジェクトでは IntelliSense（コード補完）のパス解決を **CMake Tools 拡張機能に動的に委譲** しています。設定の競合を防ぐため、静的な絶対パスが記述される `c_cpp_properties.json` はリポジトリに含めません。共有すべきデバッグ設定と推奨拡張機能のみをホワイトリスト化（`!`）して管理しています。

### 4. OS 固有ファイル & 一時ファイル
* **除外対象**: `.DS_Store` (macOS)、`Thumbs.db` (Windows)、各種ログ (`*.log`)、一時ファイル (`*.tmp`)
* **理由**: 異なるOSを使用する開発者が混在する環境で、OS特有の隠しファイルやサムネイルキャッシュがコミットに混入するのを防ぎ
